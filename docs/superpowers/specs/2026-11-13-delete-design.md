# Delete a mistaken application

Use /delete with one owned application option and a private Delete / Cancel prompt.
This permanently removes the existing Discord post and its history, then the
application and dependent D1 records. Withdrawn remains the ordinary end of an
application. Archive and bulk deletion are outside scope.

Opening stores a 10-minute confirmation of the current owner, Forum, thread
and application revision without locking the application. Confirm revalidates
ownership and claims the shared status/edit slot only if the snapshot is current.
Cancel can only change an open prompt. Redelivery and duplicate clicks cannot
start another delete. Buttons are removed from the original private response
when the operation finishes.

Check that Discord returns the mapped Forum and exact child thread before DELETE.
Only the matching successful DELETE response allows D1 removal. Preflight and
definite rejections release the claim; uncertain results retain the record and
claim with a reference for manual recovery. Keep a minimal receipt after
successful deletion to prevent delayed /apply delivery recreating the post.
No new secrets, permissions beyond existing Manage Threads, or runtime services.
